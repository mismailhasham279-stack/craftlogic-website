==================================================
DESIGN DIRECTION
==================================================

Create a premium dark, minimal and highly interactive visual identity.

Color palette:
- Deep navy / near-black background
- White typography
- Soft silver/gray secondary text
- One subtle electric-blue accent
- Avoid excessive colors

Typography:
- Use a modern, premium, bold sans-serif font for headings.
- Use a clean highly readable font for body text.
- Strong typography hierarchy.
- Large confident headlines.
- Avoid decorative/fancy fonts.

Overall visual style:
- Premium
- Minimal
- Sophisticated
- Modern
- Developer/creative studio aesthetic
- Lots of whitespace
- Clean grid system
- Strong visual hierarchy
- High-quality spacing
- Subtle glass effects where appropriate
- Soft borders
- Very subtle gradients
- No excessive rounded cards
- No random colorful gradients
- No unnecessary emojis
- No generic stock illustrations

Do NOT make the website look like an AI-generated landing page.

==================================================
ANIMATION & INTERACTION
==================================================

The website should feel highly interactive and polished.

Use smooth, purposeful animations throughout the website:

- Smooth page transitions
- Scroll-triggered reveal animations
- Staggered text animations
- Smooth section transitions
- Subtle parallax effects
- Interactive hover states
- Magnetic-style buttons
- Animated navigation
- Subtle background motion
- Smooth image reveal animations
- Project card hover interactions
- Cursor interaction on desktop where appropriate
- Animated process timeline
- Subtle floating website mockups

Animations must feel premium and intentional.

DO NOT over-animate every element.

The animation should enhance the content rather than distract from it.

Respect prefers-reduced-motion accessibility settings.

On mobile devices, reduce heavy animations for performance.
